# syncingRails

Team vault + code for Hack The Rails (Track 2, Trip Planner built with Stripe).
Open this folder as an **Obsidian vault**, and start at `00 Home`. The code is in `app/` (see `app/README.md`).

## Team setup (10 min)
1. Install **Obsidian** (https://obsidian.md) and **Git** (https://git-scm.com).
2. Clone: `git clone https://github.com/LamaAboukhalilUCLL/syncingRails.git`
3. Obsidian → **Open folder as vault** → pick the `syncingRails` folder itself.
4. Settings → Community plugins → **Turn on** → Browse → install and enable **Git**. Its sync settings are already in the repo.
5. Edit a note, wait ~5 min, check the commit appears on GitHub.

Rules: one person per note · own note in `05 Build log` · small edits to `Status` · decisions in `04 Decisions/Decision log` · declare tools in `06 Submission` · **never commit API keys**.
