# How to log your work

Make a **new note** per work session, named:

`YYYY-MM-DD HHMM topic (your name)`, e.g. `2026-11-21 1300 voice search (Lama)`

Copy this template:

```
# <title>
**Who:**
**What I did:**
-
**What works / what's broken:**
-
**Next:**
```

Don't edit other people's logs. Update your line in [[Status]] when you finish.
